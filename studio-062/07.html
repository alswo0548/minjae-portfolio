07. API 명세

작업 단위 HTTP 인터페이스

POST /api/jobs에 category_id와 title을 전달하면 생성된 작업 id를 받는다. PUT /api/jobs/{job_id}/answers는 answers와 추가 행 정보를 저장한다. POST /api/jobs/{job_id}/media는 multipart 파일을 받는다.

POST /api/jobs/{job_id}/package로 회차 자료를 구성한다. POST /api/jobs/{job_id}/drafts는 같은 편의 다음 버전을 만들고 GET /api/jobs/{job_id}/drafts에서 저장 기록을 확인한다.

접근 출처가 허용 범위를 벗어나면 403, 보호 중인 작업과 이동·정리가 경합하면 409로 응답한다. 부록의 API 목록은 v0.6.2 FastAPI 라우트에서 추출했다.
